Makhzani (مخزني)

Enterprise Warehouse, Inventory & Stock Audit System
Flutter (Windows Desktop / Web / Mobile) · Real-time Sync · Offline Resilience

منظومة برمجية متطورة لإدارة المخازن والمستودعات والرقابة الشاملة على الأرصدة وحركات التوريد والصرف، مصممة بهندسة برمجية صارمة للقضاء النهائي على عجز الجرد وفوضى الدفاتر. تتميز المنظومة بـ نبض فوري للرصيد، ودورة ذكية لمعالجة المرتجعات وتسوية الموردين، وجلسات جرد رقمية تفاعلية تطابق المخزون الفعلي مع رصيد النظام وتعتمد الفروق بضغطة زر واحدة.

🔄 End-to-End Operational Lifecycle (دورة العمليات المخزنية المتكاملة)

يبدأ المسار بـ تكويد الصنف التلقائي وتحديد الرصيد الافتتاحي ← متابعة نبض المخزن وحركات الوارد والمنصرف اللحظية ← معالجة المرتجع المزدوج (إرجاع للمخزن + تسوية المورد) ← إتمام جلسات الجرد الرقمية ومطابقة العجز والزيادة واعتماد الفروق دفعة واحدة.

⚡ نبض المخزن والرصيد اللحظي

لوحة مراقبة فورية تعرض الرصيد الحي، تنبيهات الأصناف منخفضة الرصيد لتفادي النواقص، مع اختصارات تشغيل سريعة لتسجيل حركات الوارد والمنصرف والطباعة الفورية.

🔁 دورة المرتجع وتسوية المورد

معالجة ذكية ومترابطة؛ بمجرد استقبال المرتجع يُعاد حسابه في رصيد المخزن فورياً، مع توثيق الحركة وتعليق مستحقات المورد حتى اعتماد الاستبدال أو التسوية المالية.

🎯 جلسات الجرد ومطابقة الفروق

جلسات جرد رقمية تمكن أمين المخزن من عدّ الواقع الفعلي لكل صنف، واحتساب الفروق تلقائياً ضد رصيد النظام، واعتماد التسوية المخزنية بضغطة زر دون توقف العمل.

  • Supabase Flutter: إدارة التخزين السحابي وقواعد البيانات اللحظية ومزامنة الأرصدة عبر الأجهزة.
  • BLoC / Cubit & Equatable: عزل منطق الأعمال تماماً عن واجهات المستخدم لضمان استقرار العمليات المحاسبية.
  • PDF, Printing & ESC/POS: توليد التقارير والفواتير تلقائياً والطباعة الحرارية على طابعات الإيصالات.
  • Excel & File Picker: تصدير واستيراد بيانات المخزون وجداول الجرد بصيغ XLSX للتكامل المحاسبي.
  • Flutter Secure Storage: تشفير وحماية مفاتيح الاتصال وجلسات دخول أمناء المخازن.
  • Window Manager: تخصيص تجربة التشغيل على أنظمة Windows Desktop بحجم وخصائص متوافقة.

  • Pinput: حقل إدخال كود التحقق (OTP) مخصص وذو استجابة سلسة.
